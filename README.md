# Aura Intelligence

Aura Intelligence is a premier platform for high-priority architectural brand blueprints and neural copy generation. It empowers businesses to transform raw data into sophisticated visual matrices and production-ready React codebases with near-instant synthesis.

## 🚀 Key Features

- **Neural Engine Synthesis**: Uses advanced context models (Gemini 1.5 Pro) to map vertical-specific data into high-conversion design architectures and copy.
- **Aesthetic Matrix V2**: A sophisticated UI for exploring dynamic visual themes, typography pairings, and layout configurations.
- **Blueprint Protocol**: Generates high-fidelity React/TypeScript blueprints pre-configured with Tailwind CSS utility classes.
- **Architectural Workflow**: Streamlined design-to-deployment workflow including SEO mapping and localized copy generation.
- **Neural Dispatch**: Integrated dispatch system for receiving architectural updates, patch notes, and system transmissions.
- **Partner Ecosystem**: Integrated with global infrastructure including Stripe, AWS, and the Antigravity Network.

## 🛠 Tech Stack

- **Core**: [React 19](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Server**: [Express](https://expressjs.com/)
- **Neural Engine**: [@google/genai](https://ai.google.dev/) (Gemini 1.5)
- **Deployment**: [Vite](https://vitejs.dev/) + [esbuild](https://esbuild.github.io/) for high-performance bundling

## 🏁 Getting Started

### Prerequisites

- Node.js (LTS v20+ recommended)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd aura-intelligence
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Create a `.env` file in the root and add your Gemini API key:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

### Development

Run the development server (Express + Vite):
```bash
npm run dev
```
The application will launch on `http://localhost:3000`.

### Production Build

Generate the optimized production bundle:
```bash
npm run build
```
This command builds the frontend static assets and bundles the server using `esbuild`.

Start the production instance:
```bash
npm run start
```

## 📐 Project Structure

- `/src/App.tsx` - Primary application logic and architectural layout.
- `/src/components/` - High-fidelity React components (Matrix, Showcase, Forms).
- `/server.ts` - Express backend with AI integration and Vite middleware.
- `/src/index.css` - Global styling powered by Tailwind CSS v4.
